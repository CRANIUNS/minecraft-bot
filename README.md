# minecraft-bot

Bot automatizado para interação com servidores Minecraft, desenvolvido em Node.js.

## Descrição

Projeto de estudo e experimentação focado em automação baseada em eventos.

O bot conecta a um servidor Minecraft e executa ações programadas, como resposta a comandos, envio de mensagens automáticas e tratamento de eventos do jogo.

## Funcionalidades

• conexão automática ao servidor  
• escuta de eventos  
• execução de comandos  
• envio de mensagens  
• estrutura modular de código  

## Tecnologias

• JavaScript (Node.js)  
• bibliotecas de bot para Minecraft  
• programação orientada a eventos  
```
node bot.js
```
